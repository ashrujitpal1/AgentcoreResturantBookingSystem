# Mock Weather Service - File Index

## 📁 Core Files

### `app.py`
Main Flask application with weather service endpoints
- `/health` - Health check
- `/weather` - Get weather for specific city, date, and time slot
- `/forecast` - Get 7-day forecast for all cities

### `requirements.txt`
Python dependencies (Flask, gunicorn)

## 🛠️ Utility Scripts

### `generate_forecast.py`
Display formatted 7-day forecast for all cities
```bash
python3 generate_forecast.py
```

### `export_forecast.py`
Export complete forecast to `forecast_7days.json`
```bash
python3 export_forecast.py
```

### `forecast_summary.py`
Display statistical summary of forecast data
```bash
python3 forecast_summary.py
```

### `test_service.py`
Test suite for API endpoints
```bash
python3 test_service.py
```

## 🚀 Deployment

### `deploy_ec2.sh`
Automated EC2 deployment script
```bash
./deploy_ec2.sh
```

## 📚 Documentation

### `README.md`
Complete documentation with setup and deployment instructions

### `QUICKSTART.md`

### `forecast_7days.json`
Exported JSON file with complete 7-day forecast (generated by export_forecast.py)

## 📊 Data Specifications

- **Start Date:** 2026-02-10 06:00:00
- **Duration:** 7 days (Feb 10-16, 2026)
- **Cities:** 8 (Austin, Boston, Chicago, Los Angeles, Miami, New York, San Francisco, Seattle)
- **Time Slots:** 4 per day (Morning, Afternoon, Evening, Night)
- **Total Entries:** 224 weather data points

## 🔧 Quick Commands

```bash
# Start service
python3 app.py

# View formatted forecast
python3 generate_forecast.py

# Export to JSON
python3 export_forecast.py

# View statistics
python3 forecast_summary.py

# Test API
curl "http://localhost:8080/forecast"
```
