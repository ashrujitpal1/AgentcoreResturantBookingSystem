# Restaurant Booking Streamlit Frontend

Minimal Streamlit chat interface for the Restaurant Booking System.

## Setup

```bash
cd frontend
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Usage

1. Enter your **User ID** (actor ID) in the sidebar
2. Start chatting with the assistant
3. Ask about restaurants, make bookings, or check reservations

## Features

- User ID input as actor identifier
- Session management with unique session IDs
- Chat history persistence
- Direct AgentCore Runtime integration
- New session reset button
